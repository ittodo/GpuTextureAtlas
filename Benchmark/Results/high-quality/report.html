ASTC · BC7 HighQuality 비교

저장된 측정 이후 인코더 코드가 변경됐습니다. 아래 수치는 측정 시점 구현의 결과입니다. 현재 프레임 분산 측정을 별도로 확인하십시오.

Fast·Balanced·HighQuality를 같은 실행에서 비교했습니다. 해상도마다 알파 10장과 비알파 10장입니다. 기존 6.6 측정은 보존했습니다. 아래 시간은 데스크톱 D3D12의 처리량입니다. 모바일 기기 시간은 측정하지 않았습니다.

알파 표본은 공식 이미지 5장, 독립 알파 마스크를 붙인 사진 4장, UI atlas 1장입니다. Arm 원본 3장은 256×256이며 큰 입력에서 확대했습니다. 원본과 변환 기록은 출처 목록과 입력 manifest에 있습니다.

품질과 시간 · 각 10장 집계

형식 · 품질RGBA PSNR ↑RGB PSNR ↑알파 PSNR ↑합성 PSNR ↑GPU 버퍼 처리량 ms ↓BC7 텍스처 갱신 ms ↓동기 API ms ↓

RGBA·RGB·알파·합성 PSNR은 MSE를 합쳐 계산합니다. GPU 버퍼는 8회 제출 후 한 번 완료를 기다린 3묶음의 중앙값입니다. BC7 텍스처 갱신은 압축·GPU 복사·샘플링 완료를 포함합니다. 이때 묶음 끝의 검산용 readback 비용 일부도 포함합니다. 정상 EncodeFrame에는 readback이 없습니다. GPU timestamp나 프레임 지연 수치가 아닙니다.

국소 오차

형식 · 품질최대 절대오차 ↓P99 오차 평균 ↓최악 블록 PSNR ↑HQ 개선 블록HQ 증가 블록

개선·증가 블록 수는 Balanced 대비 정수 RGBA 제곱오차로 계산합니다. 개별 RGB·알파·합성 PSNR은 서로 교환될 수 있습니다. ASTC는 탐색에 사용한 보간 오차와 공식 디코더의 반올림이 달라 일부 블록의 정수 오차가 증가할 수 있습니다. BC7은 블록별 RGBA 오차 증가가 없는지 검사합니다.

모드와 검산

ASTC는 공식 Arm astcenc 5.7.0으로 복원했습니다. 모든 새 BC7 결과는 하드웨어·별도 스칼라 디코더를 정확히 대조했습니다. BC7 2분할 모드는 64개 패턴과 anchor를 192개 독립 비트 표본으로 대조합니다. 측정 입력 60개 해시와 540개 조합을 보고서 생성 때 확인합니다.

ASTC HighQuality: 기존 Balanced 후보를 포함하고 16개 격자 모드·추가 초기 끝점·RGB/알파 분리 평면·4회 끝점 보정·지역별 격자 보정을 비교합니다. 단일 분할 LDR입니다. BC7 HighQuality: GPU에서 Balanced 결과를 먼저 저장합니다. 기존 모드 4·5·6 탐색을 늘리고, 64개 분할을 빠르게 평가한 뒤 상위 4개에서 모드 1·3(불투명) 또는 7(알파)을 정밀 탐색합니다. 모드 0·2와 3분할은 없습니다.

HighQuality는 품질을 우선하는 선택입니다. 기본 Fast는 유지합니다. 1024² 이상을 매 프레임 압축할 때는 해당 기기에서 시간·발열을 측정해야 합니다. astcenc medium 이미지는 기존 저장 결과를 품질 참고로만 표시합니다. 그 CPU 속도와 새 GPU 시간을 같은 실행의 속도 배수로 비교하지 않습니다.
