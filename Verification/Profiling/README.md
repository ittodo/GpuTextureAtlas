# 관리 객체 할당 진단

Unity 6000.7.0b5에서 시험한 별도 진단 수집기다.
GpuTextureAtlas UPM 패키지에는 포함하지 않는다.
게임 클래스의 생성자나 메서드에 카운터를 추가하지 않는다.

| 대상 | 연결 방법 | 기록하는 값 |
|---|---|---|
| [Windows CoreCLR](CoreClr/README.md) | Player 실행 환경 변수로 네이티브 DLL 연결 | 클래스별 할당, GC 생존 추적에 따른 회수 |
| [Android IL2CPP](AndroidIl2Cpp/README.md) | 개발 APK에 네이티브 라이브러리와 부트스트랩 추가 | 클래스별 할당, GC 후 짧은 약한 참조 소실 |

Android의 약한 참조 소실은 정확한 메모리 반환 횟수가 아니다.
객체 부활 검산으로 이 차이를 확인했다.
두 도구 모두 관리 객체를 관측한다. GPU 메모리나 Unity 네이티브 객체의 해제는 세지 않는다.

`Results/`는 2026-10-24에 검산한 기록이다. 현재 실행 상태를 나타내지 않는다.
수집기 소스와 별도 검산 코드를 함께 보관한다.
빌드와 새 측정 결과는 Git에서 제외한 `.validation/`에 저장한다.
Unity 설치 파일, 생성된 검산 프로젝트, DLL·SO·APK와 전체 로그는 포함하지 않는다.

모든 할당을 추적하므로 계측 비용이 크다.
범용 성능 프로파일러나 배포용 게임 기능으로 검증한 도구는 아니다.
지원 조건과 재실행 방법은 각 문서를 따른다.
